# 정다운 · 새벽소리

사운드 아트 작가 정다운의 텍스트 중심 작업 아카이브입니다. 첫 화면은 ‘새벽소리 / 정다운 / 사운드 아티스트 · 작곡가 · 프로듀서’로 소개하고, 그 아래에 제공된 CV를 바탕으로 전시, 공연 음악, 영상·광고, 프로듀싱·작곡·편곡, 믹싱·마스터링, 연주, 포스트 프로덕션, 강의·연구를 정리했습니다.

## 실행

Node.js 20.19 이상 또는 22.12 이상이 필요합니다. 이 환경에서는 Node.js 24와 npm으로 확인했습니다.

```sh
cd /workspace/homepage
npm ci
npm run dev
```

```sh
npm run build
npm run preview
```

`dist/`가 정적 배포 결과입니다. 개발 서버와 미리보기 서버는 기본적으로 `0.0.0.0`에 바인딩합니다. 인터넷 공개나 환경 게시는 별도 작업이며 자동으로 수행하지 않습니다.

## GitHub Pages 배포

소스 저장소는 `founchgit/homepage`의 `main` 브랜치입니다. 공개 사이트는 `gh-pages` 브랜치의 루트(`/`)를 GitHub Pages에서 서비스합니다. `vite.config.js`에서 상대 경로를 사용하므로 `/homepage/` 아래에서도 CSS와 JavaScript를 불러옵니다.

내용을 수정하면 먼저 소스를 커밋한 다음 `npm run build`로 새 `dist/`를 생성하고, 그 결과와 `.nojekyll` 파일을 `gh-pages` 브랜치에 배포해야 합니다. `main`에 소스만 올리는 것으로는 공개 사이트가 갱신되지 않습니다. 환경 게시와 홈페이지 배포는 별개입니다.

## 내용 수정

- `src/cv.js`: 이름, 학력, 8개 카테고리와 전체 CV. 연도 미기재 작업은 `—`로 보존합니다.
- `src/main.js`: 아카이브 화면, 분야 필터, 검색, 더 보기와 인쇄 처리. 작업 제목과 링크는 CV 데이터에서 가져옵니다.
- `src/style.css`: 색상, 타이포그래피, 모바일·인쇄 레이아웃.
- `index.html`: 페이지 제목과 검색 설명.

첫 화면의 아카이브에서 8개 분야와 검색어를 조합해 이력을 탐색할 수 있습니다. 브라우저 인쇄 역시 전체 이력을 보여줍니다. 외부 작업 링크는 새 창에서 열립니다. 소개, 대표 작업 탭, 상단 메뉴, CV 다운로드 버튼과 푸터는 표시하지 않습니다.

공개 연락처가 제공되지 않아 이메일이나 문의 전송 기능은 넣지 않았습니다. CV의 영화제 후보 표기와 공개 예정 표기는 제공된 이력을 유지하며, 완료 또는 수상으로 바꾸지 않았습니다. 작업 이미지, 음악 파일, 외부 폰트와 분석 도구를 가져오지 않아 외부 자산 요청 없이 페이지를 볼 수 있습니다.

음반과 기존 연주·편곡 작업은 크레딧에 따라 프로듀싱·작곡·편곡, 믹싱·마스터링, 연주로 분류합니다. 여러 역할이 있는 작업은 각 분야의 필터에 포함되며 전체 작업에서는 한 건으로 집계합니다. `src/cv.js`의 `roleCategories`에 역할별 작업 ID를 기록하고, `categories` 배열로 분야를 연결합니다. 전체 보기에서는 주 분야별로 한 번만 표시합니다.
